# 项目管理系统

面向可信局域网的本地项目管理系统。以项目进展甘特图为主屏，自动计算需求状态、进度和风险，并提供模板排期、计划/实际 Gap、人员矩阵、归档管理和带 Token 认证的 MCP 服务。

## 主要能力

- 项目进展：KPI、可筛选的需求级甘特图，以及可展开的工作项明细。
- 自动管理：根据工作项日期和阻塞状态推导需求状态、加权进度与风险。
- 模板排期：支持开始偏移、工期、并行与交错，并可拖动调整工作项顺序。
- 多人协作：工作项默认一名主负责人，也可增加协作人员；并发分析计入每位参与者。
- 人员矩阵：按岗位自动分组，并展示今日排行与未来四周并发度。
- 系统管理：归档恢复与删除、审计、备份恢复、MCP Token 管理。

## 技术栈

TypeScript、React、Vite、Fastify、SQLite、Drizzle 和 ECharts。默认开发分支为 `dev`。

## 启动

1. 首次使用先运行 `npm install`，复制 `.env.example` 为 `.env`，再执行 `configure.ps1` 完成账号配置。
2. 双击 `start.bat`，或运行 `npm run build` 后执行 `npm start`。
3. 本机访问 `http://localhost:3210`；局域网其他电脑访问 `http://本机IP:3210`。
4. 访客无需登录，只能查看；点击右上角“用户登录”后可维护数据。

初始账号为 `user`。安装完成后建议立即运行：

```powershell
.\configure.ps1
```

该脚本会重新设置用户名、密码哈希和会话密钥，不建立复杂用户系统。当前使用HTTP，请仅在可信局域网中使用。

## MCP

登录后进入“Token与审计”，创建Token并立即复制。MCP地址：

```text
http://本机IP:3210/mcp
```

客户端请求头：

```text
Authorization: Bearer pm_xxx_xxx
```

MCP 支持项目、需求、工作项、进展、模板和人员维护，以及排期、人员并发、归档和审计查询；不开放登录凭据、Token 管理和数据库恢复。

## 使用要点

- 新建需求只需填写标题、优先级、计划开始和模板，工作项及计划日期自动生成。
- 工作项通过“开始、完成、阻塞、解除阻塞、取消”推进；需求状态、加权进度和风险随之自动变化。
- 进展只填写具体内容，可选关联工作项；关联未开始工作项时自动记录实际开始。
- 模板用“开始偏移＋工期”表达顺序、并行和交错；修改模板只影响之后的新需求。
- “人员矩阵”按岗位分组，并展示今日排行及未来四周工作日热力图。
- 项目、需求、人员和模板归档后，可在“系统管理”的归档中心恢复或删除。

## 数据与备份

- 数据库：`data/project-manage.db`
- `.env`、数据库、备份、构建产物和依赖目录均不提交到 Git。
- 自动备份：每日02:00，保留30天
- 手动备份/恢复：登录后进入“Token与审计”
- 升级使用编号迁移，不会重新初始化或覆盖现有数据库；升级前仍建议先执行在线备份
- 现有需求的“补全计划”先显示差异，只填空缺日期，不覆盖已有计划和实际日期
- 延期和Gap按工作日计算，默认只排除周六、周日

```powershell
npm run build     # 类型检查并构建

```
