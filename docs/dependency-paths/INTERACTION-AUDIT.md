# 第二轮交互检查与修复

2026-09-08。基线 `9bc0eb2`，范围为全局路径、需求内部路径、流程设计的共享工作区。仅更新 3220／5174，不改服务端契约及数据库结构。

## 检查方法

| 链路 | 检查重点 |
|---|---|
| 选择 → 多选／反选 → 关系 → 快捷操作 | 选择状态、属性对象、复制和删除范围 |
| 原位输入 → 中文确认 → 快捷保存 | 光标、输入法、文字撤销、最新预览 |
| 放置／连线／拖动 → Esc／右键／切出窗口 | 取消后不新增关系、节点或位移 |
| 浮层关闭 → 键盘继续操作 | 关闭当前层、恢复焦点、不抢其他输入框焦点 |
| 首次移动 → 刷新 → 撤销 | 草稿与初始坐标一致，正式数据无写入 |

## 修复结果

| 已复现的问题 | 当前行为 |
|---|---|
| 多选后选中关系会反复更新状态，触发页面异常 | 选择通过受控节点变更更新；关系选择清除节点选择 |
| 反选后属性仍指向被取消的节点 | 属性跟随剩余选中节点；Ctrl+A 选择当前显示范围 |
| 点击正在改名的文字会失焦 | 原位输入期间保持光标，暂停该文字区域的拖动和平移 |
| 中文输入的确认键会提前提交名称 | 输入法组合阶段不执行画布快捷键或完成改名 |
| 输入框中 Ctrl/Cmd+S 无效 | 提交当前输入后保存；缺少最新预览时先校验该快照，失败保留草稿 |
| 先关闭属性层，放置模式仍在继续 | Esc 优先取消拖动、连线或元素放置，再处理浮层 |
| 右键被当成连线确认 | 右键、中键不会提交连线 |
| 拖动途中切出窗口仍留下位移 | 失焦、页面隐藏、指针取消均恢复起始位置；后续松手不提交 |
| 搜索 Esc 关闭了其他面板，关闭浮层后键盘失效 | 优先关闭当前焦点所在面板，再恢复查找按钮或画布焦点 |
| 首次移动后撤销只退回记录，坐标没有恢复 | 缓存初始显示坐标，刷新后仍可恢复；缓存不作为正式布局提交 |
| 快捷操作可能涉及筛选隐藏项或内置验收 | 图上复制、移动、删除只处理可见选择；删除和复制排除内置节点 |

输入框保留原生文字选择、复制及撤销。保存期间暂停业务编辑；原有权限、冲突检查、预览凭据和提交回执继续生效。

初始布局缓存沿用账号、项目和需求隔离的视图存储，退出登录及权限失效时随现有视图清理。正式布局始终以已保存坐标为准。旧版本已有草稿若没有初始布局缓存，无法恢复当时未被记录的精确坐标。
