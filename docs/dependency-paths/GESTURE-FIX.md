# 画布手势检查与修复

2026-09-08，基线 `ddf9122`。范围：全局路径、需求内部路径、流程设计共用的画布。仅更新 3220／5174。

## 分析计划

| 检查链路 | 验证方法 |
|---|---|
| 拖动 → 松手 → 路由替换 | 延迟 Worker 返回，逐帧检查旧线、节点位置、临时线及最终线 |
| 四侧起点 → 卡片／空白 → 完成或取消 | 检查箭头、边缘落点、方向说明、非法目标和 Esc |
| 快速连续操作 | 检查改接、连续微移、撤销重做、乱序响应和拖动取消 |
| 其他操作干扰 | 检查浮层、缩放、键盘、页面往返、主题及减少动态效果 |
| 大图与隔离交付 | 复测 20／80／200 节点；检查草稿及正式数据，构建后复验试用地址 |

## 修复结果

| 发现的问题 | 当前行为 |
|---|---|
| 松手先恢复旧线，路由稍后才替换 | 拖动及路由等待期间隐藏过期连线和标签，保留带箭头的临时线；新路由发布后才恢复正式线 |
| 动画中断无条件显示旧线 | 连线是否可显示同时检查其端点与当前节点位置，清理动画不会解除这个检查 |
| 虚线没有箭头，结束点在卡片内部 | 临时线显示固定屏幕尺寸箭头，命中整卡后落到边缘外侧；危险目标使用错误色 |
| 回连预览穿过起终卡片 | 临时线使用圆角折线，在起终卡片外侧选通道；拖动已有节点时保持原连接侧。完整避障仍由最终路由负责 |
| 改接前置时方向和提示反转 | 箭头始终表示实际前置到后续；拖动前置端时箭头指向固定的后续卡片 |
| 键盘移动重复执行、待计算时回退旧位置 | 阻止组件重复处理方向键，从当前显示位置累计移动；普通方向键 1 单位，Shift 加方向键 10 单位 |
| Esc 后继续移动鼠标仍改变节点 | 取消后恢复拖动前位置，继续移动及松手不新增草稿命令 |
| 延迟路由在拖动途中取得坐标，取消后又回放 | 路由等待手势结束后读取起始坐标，取消后不再回放拖动中间位置 |
| 连线成功提示突然跳到画布顶部 | 连线提示随手势结束消失，保存状态继续由固定工具栏显示 |
| 大图整理中重复检查和绘制卡片 | 过期几何检查只用于手动移动；动画只更新变化卡片，移动卡片临时启用合成层，完成或中断即清理 |

手动移动的路由合并等待缩短到 80ms；结构修改仍使用 250ms。拖动过程中不请求全图布局。保存、权限、依赖事实和服务端路径分析契约不变。

## 验证记录

类型检查、Lint、生产构建及 50 个测试文件中的 506 项业务／单元测试通过。39 个浏览器用例分批通过；最后的动画优化另复验 8 项受影响用例，全部通过。浏览器覆盖三处画布逐帧检查、四侧连线、改接、键盘微移、延迟响应、取消、浮层及主题。

设备：Intel Core i9-14900K，24 个逻辑处理器，Node 24.15.0，Edge 无头模式。

| 指标 | 实测 p95 |
|---|---|
| 200 节点／600 边布局与最终路由，20 次 | 1,393.8ms |
| 自动整理动画帧间隔 | 10.2ms |
| 聚焦操作反馈 | 89.9ms |
| 持续拖动帧间隔，20／80／200 节点 | 10.1／10.1／10.2ms |

拖动检查同时确认临时箭头随坐标更新；指针事件到下一次动画帧的 p95 分别为 0.3／0.5／0.8ms。该指标来自浏览器 rAF，不能当作显示器实际呈现延迟。布局等待与计算分别记录，手动移动等待为 80ms。
