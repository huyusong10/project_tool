# 路径画布交互与布局修正

日期：2026-09-08。基线：`d2c4154`。工作区：`D:/tools/project-manage-paths`，分支：`codex/dependency-paths`。

## 行为

| 范围 | 本轮变化 |
|---|---|
| 连线 | 四侧连接点均可作为起点，整张目标卡片可接收；A 拖到 B 固定表示 A 完成后 B 开始。拖动、点击和键盘连接共用校验及单次提交入口。 |
| 鼠标 | 取消激活模式；左键拖空白平移、滚轮缩放，中键和空格拖动保留。浮层输入及滚动独立。 |
| 聚焦 | 完整布局与可见范围分开；隐藏节点不删除，不改变坐标和路由。返回全图恢复范围与视口；搜索范围外节点后可主动定位。 |
| 浮层 | 导航放左上，草稿操作放右上；详情按内容定高；底部控件同高对齐。窄屏两行工具栏、一次一个面板。 |
| 动效 | 250ms 合并结构变化；旧线路淡出 80ms、节点移动 240ms、新线路淡入 120ms。拖线暂停移动，过期布局不发布；支持减少动态效果。 |

动画期间统一时钟直接更新展示坐标和透明度，避免每帧重绘所有 React 节点及连线；命中、暂停和下一次过渡使用当前显示坐标。结束时统一提交布局。线路折点不做形状插值，移动期间隐藏受影响线路及标签。

刷新复现的问题同时修正：首次布局不再按选中节点调整独立分组顺序。已有完整布局内的局部修改仍保持操作锚点。

REST／MCP、数据库、依赖语义和批量保存契约没有变更；未新增运行依赖。

## 性能与动画采样

设备：Intel Core i9-14900K，24 个逻辑处理器，32 GiB 内存，Windows 11，Node.js v24.15.0，Microsoft Edge。

200 节点／600 条边，预热后 20 次浏览器 Worker 布局：p50 **1,111.3ms**，p95 **1,289.3ms**，最大 **1,313.2ms**，达到 p95 ≤2 秒。计时包含 Worker 往返，不包含整页加载和动画。

另将串行网络变更为分叉网络，记录节点位移和展示开销：

| 节点 | 不同中间位置 | 最大采样帧间隔 | 布局等待 | 布局计算 | 过渡实际耗时 |
|---|---:|---:|---:|---:|---:|
| 20 | 24 | 10.1ms | 252.1ms | 13.8ms | 449.7ms |
| 80 | 23 | 20.0ms | 252.0ms | 100.3ms | 444.8ms |
| 200 | 13 | 60.0ms | 492.8ms | 1,234.7ms | 730.6ms |

时间参数合计 440ms；实际耗时还包含浏览器发布布局与绘制开销。200 节点场景优化前仅出现 2 个中间位置，优化后为 13 个。此采样用于核对连续过渡，不代表所有设备恒定帧率。

原始数据：[布局](validation/canvas-browser-layout.json)、[动画](validation/canvas-motion.json)。

## 复验

所有命令在隔离工作区执行。Playwright 使用临时数据库、独立 Cookie 和 3211 端口。

```powershell
npm run verify
npx playwright test tests/responsive/path-analysis.pw.ts
npx playwright test tests/responsive/form-submission.pw.ts tests/responsive/day-night-motion.pw.ts tests/responsive/gantt-unified.pw.ts --project=office-1280
npx playwright test tests/responsive/gantt-unified.pw.ts --project=laptop-1366 --grep '统一展示状态进度|时间轴元素横向滚动'
node scripts/check-paths-preview.mjs
$env:PATHS_PREVIEW_URL='http://127.0.0.1:5174'
node scripts/check-paths-preview.mjs
```

本轮只更新隔离服务的前端资源，不迁移数据库。3210 不执行构建、迁移或重启；代码不合并、不部署到当前服务。
