# 需求详情与行动列表修正

2026-09-09，基线 `3118d2b`。仅更新 `codex/dependency-paths` 的 3220／5174 试用环境。

| 问题 | 修正 |
|---|---|
| 交付说明、按钮、负责人和指标重复堆叠 | 共用两行概览：状态与操作一行，进度、计划、偏差和风险一行 |
| 长背景、验收标准和风险原因挤占甘特 | 放入“资料”浮层；开关不改变页面尺寸，Esc 关闭后返回触发按钮 |
| P0 等标签套用单字方块 | 所有页面共用优先级徽章；行动页宽 80px，文字单行，四档颜色一致 |
| 行动多行内容越过行边界 | 列表按内容增高，窄屏改为卡片内上下排列；标题、原因、负责人保持在本行内 |
| 统计和筛选仍使用旧严重度文案 | 明确显示紧急／高（P0／P1）、正常（P2）、较低（P3） |
| 直接执行需求的详情甘特为空 | 复用需求执行事实显示一条执行时间轴，不生成工作项、不调用工作项写入接口 |
| 缺少排期仍显示零偏差 | 显示待排期或实际日期待确认；执行完成与待验收保持区分 |
| 我的工作卡片新增容器后样式失效 | 统一卡片、内容链接和执行按钮区；资料不足不再显示“计划正常” |
