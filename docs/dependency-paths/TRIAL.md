# 需求依赖与路径分析 · 隔离试用

工作区：`D:/tools/project-manage-paths`。分支：`codex/dependency-paths`，本轮基线 `d2c4154`。

访问：[http://127.0.0.1:3220](http://127.0.0.1:3220)。管理员访问资料在工作区 `.preview/access.txt`。

## 入口

| 页面 | 使用方法 |
|---|---|
| 侧边栏 → 路径分析 | 项目需求汇总画布。顶部显示交付目标；底部打开节点、阻塞、余量和关系浮层。 |
| 需求详情 → 路径分析 | 工作项与外部交付画布。全局进入时保留来源目标；退出恢复详情位置。 |
| 编辑关系 | 从前置卡片任意一侧连接点拖到后续卡片任意位置，或点击连接点后点击卡片。A 拖到 B 表示 A 完成后 B 开始。右侧仍可勾选前置、移除标签或清空。 |
| 部分交付 | 在需求内部点击“引入外部交付”，搜索外部工作项并连线。聚合边需先选择具体关系。 |
| 工期与预测 | 编辑状态下选择工作项，在右侧修改工期、最早开始、解阻和预测日期；统一保存草稿。 |
| 排期预览 | 先处理未保存草稿，再对照当前与建议计划，单独应用日期。 |
| 流程设计 | 新建／编辑打开页面画布。选中节点添加后续、并行工作；输出点拖到空白可创建工作。旧偏移保留至明确确认依赖建议。 |
| 项目进展 / 异常行动 | 使用正式项目分析；草稿不改风险与甘特。默认风险排序及用户主动排序继续保留。 |

左键拖动画布空白平移，普通滚轮以鼠标位置为中心缩放；中键、空格＋左键也可平移。无需激活画布。Esc 取消当前连线；浮层独立滚动。单击节点只选择，“定位”才移动视口，“适配视图”调整当前范围的缩放。

“聚焦分支”只隐藏其他节点，保留完整布局。顶部显示分支名称和节点数量；“返回全图”恢复原范围、节点位置及视口。搜索可找到分支外节点，点击“定位”会先退出聚焦。左右底部工具栏对齐，窄屏排列为两行；详情面板按内容决定高度。

连线成功立即加入草稿并显示反馈。结构修改合并等待 250ms 后布局；旧线路淡出、节点移动、新线路淡入分别为 80／240／120ms。新连线手势会暂停节点移动；系统开启“减少动态效果”时直接更新完整布局。

项目全局与需求内部共享草稿；模板草稿独立。草稿按账号和项目保存在当前浏览器会话，支持刷新恢复、撤销和重做。保存前显示“未保存预览”；版本冲突保留修改，核对后重新预览。提交结果未知时查询批次回执，同批次重试不重复写入。

关系使用“完成后开始”，多个前置全部满足。提前开始需要记录执行例外；服务器校验工作项与依赖版本，保留原关系。源工作取消、未知解阻、未核对依赖、工期缺失、过期预测均会明确显示，受影响目标不输出确定交付日期。

两级视图使用同一份完整项目网络。局部目标只改变路径高亮与余量，不改变项目风险。需求级图汇总工作项关系，允许合法的需求级 A↔B；实际执行网络必须无环。

## 样例

| 项目 | 场景 |
|---|---|
| 交付依赖试用 | 接口交付→订单联调的部分交付；订单验收→版本发布的整需求约束；已知解阻假设、预测延期及未核对的待规划需求。 |
| 路径异常试用 | A 设计→B 开发→A 联调的合法往返；未知解阻、已取消的前置、等待验收、并列分支。 |

样例使用运行脚本当天的工作日。跨日后预测会重新计算；历史解阻假设过期时会转为待确认。种子脚本按项目名检查是否已创建，重复运行保留所有试用修改。

## 运行

所有命令在隔离工作区执行。

```powershell
Set-Location D:/tools/project-manage-paths
npm run build
npm run start:paths
```

开发前端：`npm run dev:web -- --host 127.0.0.1`，端口 `5174`，代理指向 `3220`。不要同时在同一端口启动第二个后端。

| 资源 | 隔离位置 |
|---|---|
| 数据库 | `.preview/paths.db` |
| 备份 | `.preview/backups` |
| 密钥 | 本目录 `.env`，未提交 Git |
| Cookie | `pm_paths_3220` |
| 构建 | 本目录 `dist`、`dist-server` |
| 进程与日志 | `.preview/server.pid`、`server.out.log`、`server.err.log` |
| UI 回归 | 临时测试库、独立 Cookie、`3211`，构建在 `.playwright` |

本轮没有向 `3210` 执行构建、迁移或重启，没有写入主工作区数据库与配置。本分支未合并，也未部署到当前服务。
