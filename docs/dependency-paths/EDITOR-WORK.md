## 使用

| 操作 | 入口与结果 |
|---|---|
| 创建元素 | 左侧＋，拖入画布或点击后放置。全局提供需求、项目里程碑；内部提供工作项、需求里程碑和新建需求；流程提供工作项、里程碑 |
| 创建需求 | 使用需求管理的表单与校验，提交按钮为“加入草稿”。内部创建也属于当前项目 |
| 关联已有对象 | 添加菜单中搜索已有对象。放入的是同一个对象，不会复制数据 |
| 建立关系 | 四侧连接点均可开始，整张卡片可接收。A 拖到 B 表示 A 完成后 B 开始；支持点击连接及端点改接 |
| 调整布局 | 编辑时拖动节点；网格吸附及对齐辅助线。连线增删保留已有位置；“自动整理”可撤销 |
| 复制 | Alt＋拖动，或 Ctrl/Cmd＋C、V；所选元素及其内部关系一起复制。执行事实、实际日期与验收状态清空 |
| 查找与分析 | 左侧查找；右侧属性；底部甘特、阻塞、余量。筛选缩小范围，聚焦只淡化无关节点 |
| 返回 | 流程固定显示“返回流程列表”；需求按来源逐级返回。返回保留草稿和个人视图 |

工具按钮使用统一图标与尺寸。桌面顶栏 48px，390px 顶栏 88px。手动拖动直接跟随鼠标；定位、聚焦、面板和整理使用独立过渡，支持系统减少动态效果。

| 快捷键 | 操作 |
|---|---|
| Ctrl/Cmd＋单击、Shift＋空白拖动 | 多选、框选 |
| F2／双击名称 | 原位改名 |
| 方向键／Shift＋方向键 | 微移 1／10 个画布单位 |
| Delete | 删除草稿元素或核对正式对象的删除条件 |
| Ctrl/Cmd＋Z、Shift＋Z、S、F | 撤销、重做、保存、查找 |
| Esc | 取消连线、拖动或文字编辑，再退出聚焦／清除选择 |

快捷键作用于画布；输入框保留文字操作。正式对象的执行记录受现有取消、归档规则保护。里程碑达成后再重新打开，仍保留达成历史。

## 草稿与保存

- 项目全局与内部共享业务草稿；每个流程独立。IndexedDB 保存草稿、基线、待核对提交及最多 100 次撤销／重做；旧会话草稿首次读取时迁入。
- 切页、刷新、关闭浏览器后自动恢复。普通返回不清除；显式放弃需确认。退出登录或权限失效时清理对应数据。
- 多标签页显式接管编辑权。本机保存失败会提示；服务器响应不明确时保留原批次，先查回执。
- 新增、移动、改名、复制、关系、估算和布局预览均不写正式数据。保存使用同一事务；失败整批回滚，成功建立新基线。
- 服务端有新版本时保留修改，逐项核对冲突后重新预览。新版本到来会使旧冲突选择失效。
- 保存更新预测、风险和正式共享布局。已确认计划日期仍单独预览差异再应用；开始、完成、解阻、验收沿用执行入口。

草稿按浏览器来源、账号和项目隔离。3220 与 5174 是不同来源，草稿各自保留；团队共享的是点击保存后的正式数据与布局。

## 里程碑与排期

独立里程碑工期为零，不计入工作项数量或完成率。全部前置完成后可自动达成，也可设为人工确认；无前置时人工确认。需求验收复用已有验收事实，显示为内置里程碑。

工作项可选择“尽早安排”或“靠近交付点安排”。后者在不延误后续和交付点的窗口内向后安排。例如：

| 元素 | 建议安排 |
|---|---|
| 接口实现，2 日 | 第 1—2 日 |
| 文档整理，3 日 | 第 3—5 日 |
| 接口交付，1 日，靠近交付点 | 第 5 日 |
| 共同交付里程碑 | 文档与接口交付完成后的第 5 日 |

工期或解除日期未知时不承诺确定日期。网络余量与排期缓冲分别计算；靠后安排消耗的缓冲不会继续算作安全余量。

前置完成不会自动启动后续。负责人确认尾项后可以提前开始，记录操作者、时间及当时的未完成前置。预测尊重实际开始，原前置及其他依赖仍保留。
