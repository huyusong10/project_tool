# 路径工作区交互层重构

2026-09-08，基线 `ea27288`。仅在 `codex/dependency-paths`、3220／5174 隔离环境实施，无服务端契约或数据库结构变更。

## 状态归属

| 状态 | 管理位置 | 保存与刷新 |
|---|---|---|
| 业务草稿、撤销、字段缓冲、初始布局、保存状态 | `EditorSession` | 按账号、项目／模板复用内存会话，IndexedDB 顺序写入 |
| 节点集合、主节点、关系选择 | `EditorInteraction` | 三种互斥选择，页面、列表、React Flow 共享 |
| 移动、连线、改接、放置、字段输入 | `EditorInteraction` 操作标识 | 完成与取消只能发生一次，不持久化手势 |
| 实时显示位置、端口、线路、动画 | `GraphScene` | Worker 结果检查结构、坐标与请求序号；显示缓存不参与业务保存 |
| 浮层、焦点、全局指针事件 | `WorkspaceRuntime` | 浮层注册边界与触发点，共用一组监听 |
| 筛选、聚焦、搜索、来源地址 | 工作区个人视图 | URL 序列化与浏览历史恢复，不进入业务撤销 |

`DependencyGraph` 只保留场景入口及类型。项目和模板通过 `EditorAdapter.dispatch(command)` 接入各自业务规则；创建、移动、复制、连线及保存沿用原业务服务。

## 操作规则

- 开始操作记录标识及原状态；移动只改变临时预览，完成一次加入草稿，取消恢复原状态。迟到和重复事件不再提交。
- 连线使用四侧起点、整卡落点和带箭头预览。修改关系只路由，不重新摆放节点；主动整理仍可撤销。
- 字段由同一组件管理原位和属性编辑，原生文字撤销、中文组合输入继续有效。有效输入完成后加入草稿，无效原文留在字段缓冲。同名字段只有当前编辑者能提交，原位取消不会被属性面板再次写回。
- 保存先提交当前字段；隐藏的错误字段会重新打开并获得焦点，组合输入未结束时延后一次。保存中同项目其他画布也禁止修改，允许导航；响应返回后不拉回原页面。失败保持草稿，结果未知时核对原批次回执。
- 点击已选节点也能重新打开属性。关闭浮层恢复触发按钮或画布；点击其他节点原位切换内容。
- 路由失败保持用户当前位置和临时线，重试不回退；失效线路不会重新显露。
- 原位改名及属性输入中的 Esc 取消字段修改；未修改的字段允许 Esc 继续关闭当前面板。

## 兼容与清理

本机记录增加 `formatVersion: 2`、`layouts` 和 `fields`，原业务历史快照及待核对批次不改变。旧记录从 IndexedDB 读取，缺失时才读取 sessionStorage；迁入写入成功后删除会话副本。未知格式保留原记录，暂停编辑并提示。

初始布局优先采用已记录的会话基线，其次采用旧视图缓存；旧记录从未保存的坐标无法精确还原。自动生成恢复基线不会写入正式布局或增加撤销步骤。

保留最近 100 次撤销。页面离开后内存会话仍可复用，最后一个使用者离开且保存结束后释放多标签编辑权。刷新卸载不能重新占用编辑权。本机写入成功才显示已保留。

删除原独立浮层监听器、画布内选择副本、页面选择回调接口、浮层 CSS 排除名单，以及旧的 140／152px 顶栏和查找条覆盖。浮层与画布同级，桌面顶栏 48px、窄屏 88px。
