# 全局交付条件编辑

全局需求卡片拉线默认建立“验收后开始”。点击连线即可细化交付条件，不必先进入需求内部添加已有对象。

| 关系详情 | 默认 | 可选择 |
|---|---|---|
| 等待什么完成 | 前置需求验收 | 同需求的工作项、里程碑 |
| 完成后允许什么开始 | 整个后续需求 | 后续需求的工作项、里程碑 |

后续条件默认收起；已有指定端点时展开。候选超过 5 个时提供名称及拼音搜索。

单条关系显示具体条件，例如“设计交付后开始”“设计交付 → 开发联调”。多条关系显示数量，先选择其中一条再修改。长标签省略，悬停显示包含需求名称的完整端点。竖直连线旁同样放置水平标签，避让卡片、线路和其他标签。

调整使用一次替换命令：移除旧条件、加入新条件，按最终执行网络检查重复和循环。失败保留原关系并在字段旁显示原因；合法的跨需求工作项往返不按需求汇总图判为循环。

所有修改进入现有本机草稿，支持撤销、恢复及批量保存。保存前正式依赖和日期不变；保存不移动节点或适配视图。“查看前置交付”“查看后续工作”沿原导航返回，关系选择随地址恢复，保存后的客户端 ID 一并映射。

跨需求关系仍由项目经理维护。前置满足只表示具备开始条件，仍由人开始；偶发提前开始继续使用现有执行入口。
