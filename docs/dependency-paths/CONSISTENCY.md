# 数据表达与页面导航一致性

首页区域顺序、日常工作界面、需求 P0—P3、异常行动自动计算规则保持原状。本轮不改数据库结构和业务写入接口。

## 数据表达

| 数据 | 展示规则 |
|---|---|
| 首页未结束需求 | 包含待规划、未开始、进行中、阻塞、待验收；名称与统计范围一致 |
| 风险 | 列表和详情读取服务端风险；待验收继续展示交付风险，完成或取消后关闭 |
| 计划偏差 | 列表与详情共用显示函数；未排期、无法计算均不显示零偏差 |
| 按期率、均值 | 无有效样本显示“—”；按期率提示“暂无完成样本” |
| 数量 | 没有对象时仍显示 0 |

统计响应仅为比率、均值增加可选样本数。原数字字段兼容，REST 与 MCP 继续调用相同计算服务；旧响应未提供样本数时按原数字展示。

## 导航

| 页面 | 记忆内容 |
|---|---|
| 需求管理 | 搜索、状态、排序、滚动位置 |
| 异常行动 | 严重度、原因、负责人、页码、滚动位置 |
| 问题跟踪 | 查询条件、页码、滚动位置；不自动重开上次的详情浮层 |
| 我的工作 | 工作项状态筛选、滚动位置 |
| 人员 | 人员矩阵／人力分析视图、滚动位置 |
| 统计分析 | 时间范围、手动日期、滚动位置 |

URL 表示当前查询，显式链接优先。无查询参数重新进入时读取本次浏览会话中的个人视图。按账号、项目和页面保存；我的工作按账号保存。退出登录清理本轮增加的个人视图，存储不可用不阻止操作。

数据读取完成后恢复列表滚动位置。需求名称使用标准链接，支持键盘和新标签页；详情无应用内返回历史时进入需求管理。路径画布与甘特继续使用既有的草稿、来源及视口恢复机制。
