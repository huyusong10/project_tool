## 关系诊断

“已有前置”列表包括需求级与部分交付关系。需求级关系仍表示验收后开始。部分交付关系显示具体工作项，避免仅查看需求级选择器时误认为没有依赖。

`A.设计 → B.开发 → A.联调` 可以合法存在。再添加 `A.验收 → B.开始` 会构成执行循环。诊断展示实际链路，不放宽循环校验，也不改写原关系。

查看诊断不修改筛选条件、正式关系或草稿。关闭后恢复原显示范围。选中关系使用主题强调色，非法关系使用错误色。

## 连线路由

ELK 负责首次排布及主动整理。固定节点路由负责所有最终线路，已有节点位置不变：

- 同侧端点按对端位置排序并分散；同高度目标按横向位置排序，减少交叉。
- 优先选择短直线与少转折通道，给重合及交叉线路增加代价；无简短通道时绕过卡片寻路。
- 一般保留 28 个画布单位的端部直线；空间不足时缩短，无法通过时保留旧画面并说明原因。
- 缓存仍然有效的线路；新增障碍覆盖旧线时重新寻路。
- 最后统一放标签，避开卡片、线路和其他标签。密集范围没有标签空位时，通过悬停或关系明细查看文字。

聚焦只更新展示样式，不重建 React Flow 的节点集合或调用布局。全部过渡继续遵循系统减少动态效果设置。
