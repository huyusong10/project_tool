# 甘特连续时间轴

2026-09-09，基线 `af8a753`。更新隔离试用 3220／5174，无数据库迁移。

| 操作 | 行为 |
|---|---|
| 拖动日期表头或时间轴空白 | 横向浏览；接近边缘自动补充工作日，支持跨月、跨年 |
| 底部滑块、触控板横滑、Shift＋滚轮 | 横向浏览；普通滚轮保留纵向滚动 |
| 日／周／月 | 改变密度，保留中心日期 |
| 今天、适配全部、日期输入 | 主动定位；日期输入按 Enter 或失焦后定位 |
| 筛选、刷新、页面往返 | 保留当前日期、密度和时间轴起点 |
| 小于 360px 的工作项区域 | 操作进入名称下方，给日期保留空间 |

项目进展、需求工作项和有日期的排期预览共用 `useGanttNavigation`。移除“向后扩展”按钮、旧扩展状态和样式。无日期的预览继续显示紧凑列表。

滚动过程按动画帧更新；向左补日期时补偿显示坐标。拖动超过 5px 后抑制点击，关闭进展提示；失焦和指针取消结束手势。底部滑块固定显示，支持方向键。浏览不修改排期、草稿或执行事实。

个人视图按环境、账号及页面对象保存在 sessionStorage，兼容旧项目缩放偏好。保留时间轴起点以避免非整数密度下刷新取整造成日期标签变化。
