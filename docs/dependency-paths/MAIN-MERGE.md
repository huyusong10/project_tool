## 手动重启

1. 停止原 3210 服务。
2. 按原方式启动服务，或运行目录内 `start.bat`。
3. 首次启动自动备份并迁移，完成后访问 `http://127.0.0.1:3210`。

如首次启动失败，保留错误日志和自动备份，停止进程后再恢复；回退必须配套使用迁移前数据库与旧构建，不能让旧构建连接已升级数据库。优先使用此次启动生成的迁移前备份，避免遗漏备份后新增的业务记录。
