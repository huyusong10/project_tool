# 路径工作区筛选、导航与动效

日期：2026-09-08。基线：`0199059`。工作区：`D:/tools/project-manage-paths`，分支：`codex/dependency-paths`。

## 交付行为

| 范围 | 实现 |
|---|---|
| 默认与筛选 | 项目甘特和全局路径默认未结束，复用风险排序。预设与多条件筛选独立于分析入口；列表显示匹配项，画布补一层关联上下文。清空恢复默认，两页各自保存选择。 |
| 搜索 | 项目内需求与工作项支持名称、拼音检索。范围外结果明确标注，选择只更新详情；“查看全部并定位”才清除范围条件并定位。修正加权搜索把不匹配字段算作命中的问题。 |
| 返回 | 按直接来源逐级返回。目标、搜索、筛选、选择、聚焦、面板及视口随来源恢复；详情滚动位置按账号、项目隔离。来源不可访问时返回项目全局并说明原因。 |
| 聚焦 | 当前范围节点、坐标和路由不变。无关卡片透明度 35%，线路及标签 18%；悬停、选中、键盘聚焦和连接目标恢复清晰。原按钮、固定状态区及 Esc 可退出。 |
| 工作区 | 顶部固定高度，左上查找，左下分析，右侧详情，右下视图控制。面板内部滚动，开关不重排画布。进入窄屏先收起浮层并保留选择。 |
| 流程设计 | 默认显示画布，流程属性收起。四侧连接、整卡落点、点击连接和端点改接共用底座；前置勾选放在“更多关系操作”。旧流程转换先比较偏移，确认仅修改草稿。 |
| 数据 | 分析同一快照批量补充负责人、执行人员及排期状态。REST／MCP 共用服务。依赖、批量保存和风险计算契约兼容，无数据库迁移及新增运行依赖。 |

完整布局、筛选显示集合与聚焦强调集合分开。选择、搜索、筛选、聚焦、主题和面板变化不调用 ELK。结构变化仍使用局部布局和统一动画时钟。

## 动效与运行修正

| 操作 | 时间与规则 |
|---|---|
| 聚焦、筛选、搜索强调 | 180ms 透明度过渡；不修改坐标。 |
| 面板、详情切换 | 面板 200ms、最多 8px 位移；详情内容原位淡入 160ms，不反复展开整个面板。 |
| 定位、适配 | 260ms，定位保留缩放；没有视口变化时不启动空转动画。 |
| 结构变化 | 合并等待 250ms；旧边 80ms、节点移动 240ms、新边 120ms。新输入优先，拖线暂停移动。 |
| 减少动态效果 | 取消位移和淡入淡出，一致发布布局。 |

卡片保留两个供 React Flow 使用的隐藏连接点，实际正交路径继续使用 ELK 路由。聚焦复用业务卡片数据，布局时钟直接更新展示位置，避免每帧重建 React 卡片。

Playwright 前端使用与试用服务一致的生产构建，测试后端仍使用临时数据库和测试认证。开发服务排除 `.playwright`、`.preview` 等生成目录的监听，避免 Windows 构建替换文件时使 5174 退出。
