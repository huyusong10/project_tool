# 统一顶栏与返回

本文记录前一轮样式调整。启动、项目解析、顶栏发布和导航的现行实现与验证见 [应用基座重构](app-foundation-20260911.md)。

```text
项目 ▾ │ 页面图标／返回 · 页面标题        页面操作 │ 皮肤 · 账号 ▾
```

| 区域 | 规则 |
|---|---|
| 顶栏 | 桌面 52px；窄屏有操作时 88px，无操作时 52px |
| 导航位 | 统一为 48px，按钮显示“← 返回”；完整来源放在提示和无障碍名称中 |
| 一级页面 | 项目进展、全局路径和各列表显示与侧栏一致的页面图标，无返回按钮；图标不响应点击、不进入键盘焦点 |
| 二级页面 | 需求详情、需求路径、流程编辑在同一个槽位显示返回 |
| 加载与错误 | 使用同一个返回位；本机草稿缺失也不再另放正文返回按钮 |
| 名称加载 | 未取得对象名称时显示静态占位；取得后直接显示名称。标题基线保持不变，不闪现“需求详情”等中间标题；读取失败时显示明确的页面名称 |
| 页面操作 | 一个主操作，次要操作按可用宽度进入更多菜单；保存不收入菜单 |
| 个人工具 | 皮肤和账号位置固定；窄屏皮肤进入账号菜单 |

需求路径按记录的来源逐级返回，直接打开时返回项目路径。流程编辑始终返回流程列表。返回完成有效字段编辑，保留无效字段原文和本机草稿。

按钮出现、消失或来源变长均不改变标题坐标。菜单、主题和返回状态不触发画布重排。保存结果只替换当前地址中的草稿 ID，不重放保存开始时的旧地址。

## 实现

| 文件 | 职责 |
|---|---|
| `Topbar.tsx`、`topbar.css` | 共用图标／返回位置、顶栏分区和响应式尺寸；图标复用路由定义 |
| `PageHeader.tsx` | 页面提供标题、返回回调和操作；共用返回按钮通过插槽渲染 |
| `EditorToolbar.tsx` | 三处编辑工作区提供现有会话命令 |
| `use-path-return.ts` | 校验来源项目和历史位置，生成返回目标与提示 |

已删除 `WorkspaceBack.tsx`、`PageBack.tsx`、浮窗位移规则和摘要导航插槽。页面不再各自绘制返回按钮。

## 验证与构建

- 类型检查、Lint、生产构建通过。
- 本轮 18 项浏览器用例通过，覆盖普通详情、三处画布、长来源、逐级返回、刷新、错误状态、1920px、390px、触屏、全部主题及日夜模式。
- 坐标检查验证不同页面的导航位宽度均为 48px；图标与返回切换、来源长短不改变标题起点。窄屏加载与返回逐帧保持 88px。
- 上轮另有 4 项草稿回归通过：无效字段恢复、中文输入后保存、保存中跨画布、保存失败后的字段定位。本轮保留原操作流程。
- 首次点击与刷新使用延迟响应逐帧检查：1280px、390px 下加载占位和真实标题的起点、基线、高度相同。记录位于 `.preview/topbar-first-entry-delivery/`。
- 浏览器使用独立测试数据库和 3267 临时端口。本轮日志为 `.preview/topbar-first-entry-*.log`；导航效果截图仍可查看 `.preview/topbar-icon-delivery/`。
