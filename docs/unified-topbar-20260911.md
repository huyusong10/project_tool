# 统一顶栏交付记录

## 显示规则

```text
项目 ▾ │ 返回来源 · 页面名称       页面操作 │ 皮肤 · 账号 ▾
```

| 场景 | 规则 |
|---|---|
| 桌面 | 52px；项目、标题、操作、个人工具分区 |
| 可用宽度不足 960px | 次要操作进入菜单，账号缩为图标 |
| 可用宽度不足 640px | 无页面操作时 52px；有操作时两行、88px；皮肤进入账号菜单 |
| 390px 屏幕 | 保留返回、撤销、重做和保存；空间不足的状态说明进入“更多”，避免截成零碎文字 |
| 路径及流程 | 使用全站顶栏；原画布顶栏及其样式、尺寸计算已删除 |

保存、撤销和重做仍经过现有编辑会话。菜单支持外部点击关闭、Esc、方向键和焦点返回；打开菜单不提交属性输入。流程始终保留“返回流程列表”。

切换项目时，全局或需求路径进入新项目全局路径；流程编辑进入新项目流程列表。旧项目的对象参数和来源不带入新项目，本机草稿继续保留。

## 实现位置

| 文件 | 职责 |
|---|---|
| `Topbar.tsx`、`topbar.css` | 分区、实际可用宽度、项目与账号入口、响应式尺寸 |
| `PageHeader.tsx` | 标题、返回、上下文、状态及操作插槽 |
| `TopbarMenu.tsx` | 锚定菜单、键盘、焦点和工作区边界 |
| `EditorToolbar.tsx` | 将现有编辑命令提供给共用顶栏 |
| `GraphWorkspace.tsx` | 保留编辑会话与快捷键；浮层按画布边界定位 |

删除了流程列表中遗留的备用编辑器渲染。无编辑权限的链接不会再显示第二套标题或编辑操作。
