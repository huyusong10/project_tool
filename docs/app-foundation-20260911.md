# 应用基座重构

范围：`dev` 分支的现有工作区。保留原有业务改动，不改变数据库、接口、业务算法或草稿格式。

## 启动顺序

```text
主题、侧栏偏好、地址
        ↓
固定外壳占位 → 确认会话
                    ↓
          项目列表 ∥ 当前需求／问题
                    ↓
      页面上下文：项目、对象、标题、返回、操作行
                    ↓
       顶栏显示；正文与路径分析继续加载
```

需求和问题使用服务端返回的所属项目。页面直接读取解析阶段的查询结果，不再重新查询或回写全局项目。项目记忆仅在解析成功或主动选择时更新。失效对象不会套用其他项目。

已有流程链接只查询明确项目或当前账号记忆中的项目。流程不存在、项目不可访问和编辑权限不足均显示错误及返回入口，不遍历项目，也不静默显示无关列表。新生成的流程编辑链接包含项目参数。

## 状态归属

| 部分 | 文件 | 管理内容 |
|---|---|---|
| 外壳 | `App.tsx`、`Topbar.tsx`、`Sidebar.tsx` | 固定 DOM、尺寸、品牌占位、全局重试 |
| 页面解析 | `use-page-resolution.ts`、`page-context.ts` | 查询复用、访问检查、项目与对象归属、标题、返回及布局规格 |
| 顶栏声明 | `page-chrome.ts`、`PageHeader.tsx` | 当前页面的一份操作声明及工作区运行环境 |
| 导航 | `use-app-navigation.ts`、`page-foundation.ts` | 导航身份、字段收尾、手势取消、迟到声明隔离 |
| 个人视图 | `use-page-view.ts`、既有工作区存储 | 按账号、项目和页面恢复筛选、滚动、视口及草稿 |
| 编辑保存 | 现有 `WorkspaceRuntime` | 字段校验、中文输入、错误定位及原保存命令 |

每次结构导航建立独立声明存储。旧页面只能写入旧存储，其卸载清理不能删除新页面声明。筛选、搜索、选择和聚焦变化不建立新的页面边界。

路由使用同步更新模式，地址变化时立即提交新页面占位。正文使用局部 Suspense，避免路由过渡在新地址下短暂保留上一页标题和操作。

页面按钮、返回及 URL 模式切换共用编辑收尾。顶栏保存显式调用工作区原有的 `requestSave`，不再依赖 portal 事件冒泡。普通导航保留有效修改与无效字段原文。临时读取失败保留当前有效页面；身份或访问权限失效关闭业务页面，外壳保持原位。

## 显示规则

| 项目 | 规则 |
|---|---|
| 顶栏高度 | 桌面 52px；窄屏按路由声明固定为 52px／88px |
| 项目控件 | 桌面 128px、紧凑 112px、窄屏 88px；占位与实值同宽 |
| 图标／返回 | 共用 48px，一级页面显示图标，二级页面显示返回 |
| 响应方式 | 读取真实容器宽度，在首帧前确定；不从假定的 1200px 修正 |
| 品牌 | 未加载时显示固定尺寸占位，不先显示默认品牌名称 |
| 操作等待 | 保持操作行；资料未就绪不提供业务操作，只读页面不收缩行高 |

已删除页面 `syncProjectContext` 回写、`useProjectSelection` 状态机、多个顶栏 portal、DOM 挂载点注册、项目集合驱动的外壳 key，以及 `:empty` 决定顶栏高度的规则。`workspace-runtime.tsx` 改名为 `.ts`，保留原实现并显式提供保存入口。

## 需求首次进入补修

上一轮遗漏了站内首次打开未缓存需求。需求查询未完成时，页面把已确认的项目清空，侧栏切回加载状态；查询完成后，页面模块的 Suspense 又使用了另一种高度的占位。新增用例在修复前失败，记录到项目名称消失、侧栏文本清空，以及加载区从 340px 缩至 120px。

现在区分应用启动与站内导航：

- 启动仍等待真实项目资料；站内等待下一对象时，保留当前会话已确认的项目 ID，每次从最新可访问列表检查其有效性。
- 目标需求的项目和标题确认后一起切换；等待期间不展示目标业务内容。身份变化、访问失效或对象读取失败不沿用旧对象归属。
- 对象查询与页面模块并行加载；两个等待阶段使用同一加载矩形。

最终前端构建通过 27 项浏览器回归，包含 1912px／390px 首次站内进入、两种到达顺序、跨项目对象、冷启动、返回、编辑保存与菜单。首次进入的 4 组逐帧记录中，项目和侧栏始终保留，加载区只有一种矩形。类型检查、变更文件 Lint 和 5 项状态测试通过。

本次基于最新前端源码构建，保留同期其他功能更新。已更新 3210 前端，入口为 `index-zQl0Q-HZ.js`；发布前后 PID 49484 及启动时间相同，后端产物摘要未变。本次修复未重启服务、操作数据库或提交代码。
