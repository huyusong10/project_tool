# 进展表状态与日志关系图修复

2026-09-15。

## 界面

| 内容 | 表现 |
|---|---|
| 工作项状态 | 同一方框图标系列：空框为未开始，圆点为进行中，勾为完成，横线为取消。灰色、执行蓝色、完成绿色辅助区分 |
| 负责人 | “未分派”继续显示在负责人位置，不覆盖工作项执行状态 |
| 需求进度 | 在时间轴实际条旁显示当前阶段及百分比；并行阶段分别显示，不合成一个百分比 |
| 短条与未排期 | 进度说明保留在可见时间轴内，平移、缩放及更新不改变行高或列宽 |
| 右侧 | 只保留执行动作和更多菜单，固定列缩窄；进度数字沿用原来的更新表单 |
| Phase | 状态与需求数量放在名称下方，时间轴保留目标日期和实际交付日期 |
| 窄屏 | 并行阶段分行显示，工作项主操作与更多菜单纵向排列；名称和操作列不遮住进度 |

进展表保留已取消工作项的正式记录。关系图省略这些节点时，不再连带漏掉进展表中的记录。

## 关系图故障

“日志管理”能取得数据，但自动布置的部分独立节点只有 20px 间隔，跨 Phase 连线出口被邻近节点挡住，导致整个画布路由失败。

独立节点组间距改为 64px，保留连线出口。已有人工位置和依赖数据保持原值。只有节点与连线实际生成后，画布才报告加载完成。
