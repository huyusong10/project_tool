# 关联链接

特性、Phase、需求、工作项共用一份链接列表。名称自由填写；文档、任务、其他三种分类只影响图标和展示，不限制材料或平台。

| 位置 | 操作 |
|---|---|
| 概况 | 前三项直接打开；其余从“全部”进入资料 |
| 资料 | 完整列表；旧来源摘录继续保留 |
| 编辑 | 行内添加、改名、分类、移除；拖动或键盘排序，随表单保存 |
| 工作项资料 | 单独编辑链接，不切换页面；关闭保留输入 |

地址只支持 HTTP(S)，每个对象最多 20 项，不重复添加相同地址。粘贴 Jira 或 Confluence 地址会建议名称和分类，用户可以修改。系统不抓取外部内容或同步任务状态。

## 数据兼容

- 使用现有对象保存接口、权限和版本检查；REST、MCP、导入共用校验。
- 特性的原 `referenceLinks` 原样保留；其他对象新增 JSON 列。
- 迁移把需求的 `referenceUrl` 加入列表，保留对象 ID、版本、执行状态和原地址。
- 旧客户端单独修改或清空 `referenceUrl` 只影响对应的第一项；其他项保留。同时提交列表时以列表为准。省略列表保留，空数组清空。
- 表单草稿与待核对请求分别保存。提交结果未知时先读取正式结果，不自动重试。
- 首次启动新服务前自动备份并迁移。构建保留历史静态资源，正式服务由用户启动。
