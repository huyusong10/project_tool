# 甘特图数据口径

| 数据 | 来源与变化规则 |
| --- | --- |
| 计划日期 | 当前排期；调期只修改日期和计划偏差 |
| 实际日期、工作项进度 | 执行记录；调期不修改 |
| 预计工期 `durationDays` | 模板或首次有效排期初始化；之后由工期估算操作修改 |
| 汇总权重 `progressWeight` | 创建时固定；调期和剩余工期调整不改变权重 |
| 预测区间 `deliveryForecast` | 服务端按剩余工作、依赖和工作日历计算，随需求/工作项同次读取返回 |

需求完成度使用有效工作项的固定权重；计划进度仍按当前排期计算。新增、删除和取消工作改变交付范围，可以改变汇总比例。

甘特图的实条使用实际日期。进行中实条到统计日，已完成实条到实际完成日。未开始工作不显示进度圆点。

只有排期完整且预测晚于截止日时显示红色虚线框；未开始工作从预测开始日绘制，进行中工作从统计日之后延伸。不增加蓝色预测虚线。未排期、排期不完整、按期或提前完成的预测不画框，也不延长甘特时间范围。没有可靠预测时不补造日期。

修改排期时保留完整旧图，等待服务端重读后整体替换。需求详情、项目甘特和我的工作均使用响应内的预测，不拿独立拓扑请求覆盖它。需求里程碑优先使用需求响应中的实际记录。

历史升级先备份数据库。对缺少权重的工作项，沿审计记录倒推执行开始后的日期修改；审计不能连续核对时使用当前可确认的依据。估算保留当前工期，日期、工作项进度和历史日志保持原样。回填在事务中执行，重复启动不重复修改。

回归覆盖：日期反复修改及清空、估算单独修改、完成/取消记录、REST/MCP 查询、数据库重复升级、前置等待、旧预测响应、慢写入与慢重读。
