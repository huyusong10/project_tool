## 演示

预览：[项目交付](http://127.0.0.1:3260)。账号 `admin`，密码 `PreviewPhases2026!`。项目名含“演示”，数据为预览样例。

1. 首页查看资产管理的三个 Phase，选择 Phase 2，切换“关系图”，选择仍保留。
2. 点击“进入需求”，查看各 Phase 区域和空 Phase。资产导入显示“测试中 70%”，并行需求分别显示开发和测试。
3. 选择需求，进入工作项；在详情内更新进度或维护工作项。切回表格查看相同状态。
4. 多选需求使用“批量安排 Phase”，填写调整原因。拖动图节点不会修改 Phase。
5. 在 Phase 详情查看交付历史；重新打开填写原因，再次交付保留前次记录。未完成或空范围不能交付。
6. 编辑画布内名称后切换表格，查看“未保存”投影；返回可继续编辑、撤销或保存。正式执行遇到相关草稿时先处理草稿。

固定预览构建的目录、提交及进程记录在 `.preview/preview-runtime.json`。主仓库和 3210 正式服务未升级。
