# 对象详情统一居中弹窗

## 交付内容

| 位置 | 行为 |
|---|---|
| 特性、Phase、需求、工作项、问题 | 共用 960px 居中弹窗和 DetailWorkspace；标题、栏目与操作栏固定，正文滚动 |
| 对象导航 | 在同一弹窗切换下级对象；返回恢复栏目、滚动和输入；正文范围不变 |
| 需求工作项 | 一份清单完成行内新增、拖拽排序、人员和日期安排及执行操作；手柄支持空格提起、方向键移动、空格放下、Escape 取消 |
| 工作项详情 | 独立加载概况、资料、依赖和记录，不再挂载完整需求详情 |
| 关系图 | 空白区域选中，名称打开详情；草稿属性和正式资料分开保存 |
| 网址 | detailId、detailTab 保存详情；pathNode、pathEdge 保留图形选择；兼容旧需求、pathInspector 和 issueId 链接 |
| 输入与提交 | 关闭、返回、刷新保留输入；取消编辑清除当前草稿；原始待核对请求独立保存 |
| 菜单与键盘 | 菜单对齐触发按钮并在弹窗内避让；Escape 先收起菜单，再关闭当前操作弹窗；关闭后恢复入口焦点 |

草稿按账号、项目、对象和操作保存于当前标签页。重新打开详情先读取最新资料；版本冲突和未知响应沿用业务核对流程。提交中锁定关闭、栏目和对象切换。

本次复用原有业务接口，没有数据库迁移或新增 REST、MCP 写入接口。

## 工作项与排版修正

| 问题 | 调整 |
|---|---|
| 空工具栏与大块留白 | 没有说明和操作时隐藏工具栏；资料采用两列信息区，问题进展去掉重复卡片边框 |
| 操作栏高度不一、内容贴边 | 公共操作栏使用 30px 紧凑按钮和 44px 栏高；正文留 16px 间距，窄屏留 12px；没有菜单项时不显示省略号 |
| 完成入口重复 | “完成”打开同一确认表单，说明可留空；关闭保留输入，取消清除当前输入，结果未知时保留原请求并提供核对出口 |
| 排期提示含糊 | 甘特显示待排期数量，悬停说明工作项和缺失日期，点击打开安排；需求概况列出缺项，拆分前日期标记为计划基线 |
| 工作项行过高 | 桌面两行显示名称、状态、操作、人员和日期；窄屏字段分列，日期完整显示 |
| 操作藏在菜单 | 工作项详情直接显示执行、实际日期修正、重新打开、补录等操作；移除重复的上下箭头 |
| 拖拽只有插入线 | 公共拖拽层放在弹窗上方；虚影复用对象标题、图标和状态；禁止排序时展示原因 |
| 依赖重复显示父需求 | 外部依赖按需求归组，内部关系显示工作项或里程碑端点；工作项详情支持进入和返回 |
| 甘特操作大小不一 | 主操作固定 66×30px，菜单单独预留位置；桌面与窄屏使用相同尺寸 |

常用操作显示两字文案：开始、完成、更新、编辑、排期、修正、补录、重开等。完整含义保留在辅助标签和悬停提示中，按钮沿用主题预设。

## 行内新增与短操作

| 操作 | 行为 |
|---|---|
| 新增工作项 | 清单末尾出现一行草稿，自动定位名称；重复点击新增聚焦现有草稿。名称必填，阶段、人员、日期和变更说明按需填写 |
| 保存与取消 | 行内保存一次创建一个工作项，保留当前清单；取消删除当前输入。关闭或刷新保留草稿，冲突及未知提交保留原核对流程 |
| 工作项操作区 | 进度、主操作、日期操作、取消和删除各有固定位置；开始／完成／重开共用主操作位置，不可用的位置留空 |
| 完成、进度、日期及其他短表单 | 使用公共自适应居中弹窗，保留原详情和列表位置；完成说明可留空，不再替换整个详情正文 |
| 安排锁定 | 在现有工具栏及手柄提示中说明原因，不增加提示行推动列表；提交中仍禁止关闭和切换对象 |
