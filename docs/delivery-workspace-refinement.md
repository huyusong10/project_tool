## 改动

| 对象 | 当前行为 |
|---|---|
| 导航与归属 | 项目交付只有一个特性入口，按特性 → 需求 → 工作项进入。未指定归属的需求自动归入普通“其他特性”，不自动安排 Phase |
| 筛选与表单 | 工作区及共用详情使用统一下拉控件，支持键盘操作；选项较多时支持搜索 |
| 表格与详情 | 筛选、操作和内容分区留出间距；详情独立滚动，支持加宽；390×844 使用全屏详情 |
| 关系图 | 节点随内容增高，Phase 区域容纳节点；拖动限制在所属区域内，连线避让区域标题；外部依赖标明所属特性 |
| 选择与执行 | 表格与关系图保留同一选择，返回恢复视口；需求显示执行阶段，工作项优先显示自身进度和操作；修复详情打开时连续双击失效 |

“其他特性”沿用普通特性的模型和操作。指定具体特性的导入直接归入该特性；归属调整继续检查版本、Phase 和已交付范围。

## 预览与演示

预览：[项目交付](http://127.0.0.1:3260)。使用名称含“演示”的项目。

1. 查看资产管理的 Phase 标签，选择 Phase 2，再切换关系图，确认选择保留。
2. 进入资产管理，查看需求区域、空 Phase 和跨区域依赖；拖动需求只调整位置。
3. 双击“资产导入”需求，查看“测试中 70%”；选择测试工作项，查看自身进度与执行操作。
4. 打开筛选下拉，使用搜索或方向键；加宽详情，再缩至 390×844 查看全屏详情。
5. 在测试项目创建未指定特性的需求，确认归入“其他特性”；随后可通过归属表单调整。

固定构建目录、提交、进程和地址见 `.preview/preview-runtime.json`。预览使用独立数据库、备份、会话和技能目录。主仓库、正式数据库与 3210 服务未升级。
