# 拖拽与页面操作栏优化

日期：2026-09-16

## 交付内容

| 位置 | 调整 |
|---|---|
| 进展表 | 修复“完成”按钮悬浮时背景变浅、白字看不清的问题；悬浮和聚焦保持尺寸 |
| 工作项设置 | 拖拽手柄前置，名称与手柄固定在左侧；横向滚动后仍能排序 |
| 拖拽反馈 | 工作项、清单、看板和画布工具显示对象虚影；多选显示数量，保留目标高亮 |
| 键盘排序 | 工作项和看板用空格提起、方向键移动、空格放下；Esc 取消拖拽并保留原窗口 |
| 页面操作栏 | 左侧显示范围和状态，右侧显示视角及操作；移除无实际含义的“只读”提示 |
| 导航 | 页面与分组标题统一四字，使用“项目空间”“待办事项”“人员权限”等名称 |

操作栏按可用宽度固定为一行 56px 或两行 88px。进入编辑、切换视角、显示撤销和重做时不改变高度及视角位置。窄屏把次要操作收进更多菜单。
