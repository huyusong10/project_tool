R2：页面和组件的接口路径移入领域 API。请求 DTO 从 REST/MCP 共用 Schema 推导，响应 DTO 移至 `shared/api`，项目服务复用共享响应类型。分页读取按查询键识别请求，避免内联加载函数改变身份。工作区图响应增加格式校验。
