# 工作区样式与交互改版

2026-09-15。三个视角保留公共范围和详情表单，操作不挤动导航和正文边界。

## 界面规则

| 位置 | 行为 |
|---|---|
| 树表 | 特性使用主题色，Phase 使用紫色，需求使用青色，工作项使用灰蓝色，系统分组使用灰色；同时区分图标、行背景和字重 |
| 对象名称 | 单击查看详情；名称旁的箭头进入下一级；左侧箭头原地展开 |
| 选择 | 左侧复选框选择对象，表头选择当前可见对象；系统分组使用左侧选择菜单 |
| 行操作 | 固定尺寸的省略号菜单；进展表保留固定宽度的执行动作与行内进度 |
| 新建 | 清单右上角固定“新建”入口，菜单随范围提供 Phase、需求、特性或工作项 |
| 公共顶栏 | 面包屑、视角、状态和操作分别占用固定位置；撤销、重做和保存不改变其他控件坐标 |
| 概览与批量操作 | 概览打开浮窗；批量工具与保存提示浮在表格上方，表格预留底部滚动空间 |
| 窄屏 | 固定两行顶栏，筛选工具横向滚动；进展表左右固定列不重叠，名称最多显示两行 |
