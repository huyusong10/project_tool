# 日常操作简化

| 操作 | 当前行为 |
|---|---|
| 开始、完成 | 单击直接执行；未指定负责人时，在当前窗口选择并一起提交 |
| 更新完成度 | 百分比必填，说明可留空；单独补充说明仍需填写文字 |
| 改名、换人、改日期、新增工作项、排序 | 使用当前编辑入口保存，不再额外填写原因或重复确认 |
| 问题挂起、恢复、解决、重新打开 | 选择动作即执行；可先展开“补充说明”再选择动作 |
| 取消、返工 | 工作项直接执行；需求返工保留完成度或工作项选择，整条需求取消展示涉及工作项的影响；说明可选 |
| 画布、流程模板删除 | 加入可撤销草稿，点击保存后才修改正式数据 |
| 替换流程、批量变更、永久删除、备份恢复 | 保留影响预览或确认 |

REST、MCP 和页面使用相同规则。说明留空时，系统记录操作事实；修改完成度记录前后数值，修改业务字段记录差异。

状态、权限、日期和版本检查继续生效。提交中禁止重复操作；失败保留输入，结果不明时先读取记录，不自动重发。

本轮无需数据库迁移。验证使用临时数据库和独立构建目录，不启动或重启正式服务。
