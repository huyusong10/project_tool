# 项目工作区

项目工作区分为范围与关系、计划与进展。范围默认关系图，进展默认特性与 Phase。

| 原能力 | 新入口 | 编辑与保存 |
|---|---|---|
| 特性、Phase | 范围图及对象详情 | 既有版本化接口 |
| 需求录入、导入、批量维护 | 范围清单的需求维护 | 既有表单、导入回执与批量版本检查 |
| 结构、依赖、布局 | 范围图及共用详情 | 项目草稿，预览后保存 |
| 需求与工作项排期、执行 | 计划与进展、我的工作、对象详情 | 既有独立提交与草稿冲突检查 |
| 提测、交付、返工 | 共用对象详情 | 既有执行规则和历史记录 |
| 统计分析、异常行动 | 进展辅助入口 | 沿用全项目口径，返回恢复原范围 |
| 人员矩阵、流程设计、设置、日志 | 项目配置 | 沿用原权限 |
| 独立需求详情 | 原链接 | 共用对象内容，不嵌套执行工作台 |

Phase 排列只表达范围。执行状态、交付记录和快照取正式数据；草稿显示未保存标记。

| 任务 | 首次展示 | 详情默认内容 |
|---|---|---|
| 范围与关系 | 特性关系图；清单展示目标、完成标准、分解与归属 | 资料与分解 |
| 计划与进展 | 特性及 Phase；展开后依次显示需求、工作项 | 安排与执行 |

两个任务共享对象选择、范围和项目草稿。图形视口、清单排序和甘特时间窗口分别记忆。切换任务先保留本机输入，不自动提交；无效字段也保留。执行操作检查正式数据及冲突草稿，纯布局修改不阻塞执行。

甘特中的特性没有总百分比。Phase 使用目标与实际交付节点；需求显示阶段，工作项显示自身进度。筛选保留祖先行，不重算 Phase 的完整交付状态。归档完成需求保留只读贡献；空 Phase 可查看维护，没有展开按钮。

公共工具栏固定返回、面包屑、任务切换和操作槽位。关系图／清单切换位于范围工具区。详情覆盖主区域，不触发画布适配；窄屏使用全屏详情。

旧 `/features`、`/paths`、`/requirements` 分别进入范围清单、关系图及需求维护。`/execution`、`/analytics`、`/actions` 属于进展任务，独立需求链接继续可访问。

预览 worktree：`D:\tools\project-manage-workspace`；分支：`codex/project-workspace`；基线：`b0e0db3`。3270 为独立固定构建，3271 用于自动化测试。数据库、会话、备份、构建与技能同步均隔离；不更新 3210 或 3260。

## 预览演示

登录资料位于 `.preview/access.txt`。选择“【工作区预览】DCIM 分期交付”项目，原项目来自一致性快照。

1. 查看特性图，进入资产管理，比较 Phase 1 已交付、Phase 2 推进中、Phase 3 规划中的并行范围。
2. 进入测试需求，选中测试工作项，切换计划与进展。甘特展开并定位工作项，需求显示“测试中 · 70%”。返回范围保留选择。
3. 展开平台集成验证，查看已归档需求的交付贡献，以及包含 60 个工作项的长标题需求。搜索单个工作项时保留其祖先。
4. 查看跨特性依赖；筛选单个 Phase 后仍可追查外部前置。拖动节点只改变布局。
5. 在编辑模式修改工作项名称或阶段，切换任务查看草稿投影；从更多操作预览、保存或撤销。独立更新进度不会覆盖冲突草稿。
6. 从范围清单的需求维护录入、导入或批量安排；从进展更多操作进入全项目分析，返回恢复原范围。

停止预览后可执行 `pwsh -NoProfile -File scripts/start-workspace-preview.ps1` 重新构建并启动。端口被占用时脚本退出，不终止其他服务。演示补充脚本为 `scripts/extend-workspace-demo.mjs`，隔离核对脚本为 `scripts/check-workspace-isolation.mjs`。
