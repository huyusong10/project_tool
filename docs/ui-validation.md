## 性能样本

Edge 无界面模式，1366×768，400 行需求、跨两年，5 次样本。首绘取导航到两帧后；切换取点击到两帧后。滚动和提示移动各采集 30 帧。数值为本机观测，不能替代真实设备验收。

| 指标 | 原版 | 改造后 |
|---|---:|---:|
| 首次绘制中位数 | 246ms | 282ms |
| 换肤中位数 | 86ms（明暗） | 76ms（固定风格） |
| 甘特视图切换中位数 | — | 69ms |
| 滚动帧间隔 P95 | 11.1ms | 11.1ms |
| 提示移动帧间隔 P95 | 11.1ms | 11.2ms |

本次样本首绘增加约 36ms，交互未出现明显停顿。继续使用现有 DOM 绘制；日期索引与网格按输入缓存，浮层单独更新。原始样本和脚本：`data/ui-review/performance.json`、`data/benchmark-ui.mjs`。
