# 游客浏览

项目设置 → 编辑项目 → 允许游客查看。默认关闭；经理或管理员保存后生效。

| 范围 | 游客访问 |
|---|---|
| 清单、关系图、进展表、概览 | 可读，可筛选、展开、下钻 |
| 特性、Phase、需求、工作项 | 只读详情、说明、关联链接、业务进展记录 |
| 编辑、排序、拖拽保存、导入 | 不开放 |
| 问题、个人事务、人员管理、统计分析、审计、备份 | 不开放 |
| MCP | 始终检查 Token 和项目成员权限 |

一个开放项目自动进入进展表，多个项目显示选择入口。浏览偏好与账号隔离；登录保留网址中的项目、范围、视角和详情。登录非成员仍可按游客权限浏览。

后端仅在指定工作区 GET 接口允许游客。每次读取检查项目开关；返回人员姓名、岗位等展示字段，不返回账号和成员权限信息。游客不加载或提交业务草稿。关闭开关后接口立即拒绝；浏览器在窗口重新激活或下一次后台检查时清理旧数据，检查间隔为 60 秒。

迁移 `0037_guest_browsing` 增加 `projects.guest_visible`，现有项目均为关闭，不更改账号、成员或业务记录。

## 验证

- 接口：默认关闭、跨项目读取、非成员登录、只读接口、写入拒绝、MCP、版本冲突、撤回访问。
- 回归：账号生命周期、会话缓存、业务集成、依赖接口及多链接。
- 浏览器：六组桌面视口、390px 窄屏，三视角和四类详情、登录位置保留、项目开关、多个项目选择、撤回后页面清理。
- 使用独立数据库、端口和 Cookie；没有自动开放正式项目，没有重启正式服务。
