## 分组与拖拽

- 未指定 Phase 的需求进入“未分派阶段”分组，固定置底、默认折叠；“其他需求”内也使用该分组。
- 清单和进展表复用同一分组数据；关系图、筛选、面包屑使用同一名称。进入分组后，三个视角保留当前范围。
- 分组不创建正式 Phase，不修改需求状态或所属特性；其中的需求继续参与进展与依赖统计。
- 拖拽虚影复用原对象的名称区或卡片标题区，保留图标、字形和颜色；多选显示数量。虚影不能获得焦点或触发操作。
