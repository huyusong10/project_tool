# 界面风格与甘特图

右上角调色板按钮提供瑞士排版、暖纸森林、午夜控制台、柔彩悬浮、工业黄黑、杰瑞橙六套风格。默认杰瑞橙；保留浏览器中已保存的风格选择。旧亮色偏好迁移到暖纸森林，旧暗色迁移到午夜控制台。

杰瑞橙参考 [Figma DCIM 首页](https://www.figma.com/design/u4h9gFYTOSiyndcXem3qfg/DCIM?node-id=1-11327)：采用 `#0e0f13` 背景、`#14161b` 面板和 `#ea5514` 品牌橙，橙色用于品牌、当前选中、焦点及少量主要操作；图表使用米灰条形、冷灰蓝折线和灰紫辅助线。保留细描边与石墨面板。按钮底色加深以保证小字号文字对比度，现有布局不变。

## 使用

- 风格记在当前浏览器，多个标签页同步。换肤保留项目、页面、筛选和编辑草稿。
- 浏览器存储不可用时，换肤、项目选择和侧栏折叠仍可在当前页面使用。
- 甘特工具栏的图层按钮切换“现有视图”和“计划·实际双轨”，默认现有视图。视图偏好按浏览器和账号保存，首页、需求详情、我的工作共用。
- 双轨上方是计划日期，下方是实际执行日期。完成度标签不改变执行条的长度。
- 执行中记录截至服务端统计日期；取消记录截至取消日期；已完成记录截至实际完成日期。执行跨度包含阻塞和间断。
- 时间轴按现有中国工作日日历绘制。假期内的短区间显示边界点，提示保留原始日期。重叠里程碑的提示合并展示同一位置的记录。
- 长标题使用顶栏剩余宽度。超长标题可悬停或用 Tab 聚焦查看全文。

## 维护

| 文件 | 职责 |
|---|---|
| `src/client/theme.ts`、`themes.css` | 六套风格、偏好迁移、语义样式变量 |
| `src/client/styles.css`、`responsive.css` | 公共组件及现有布局 |
| `src/client/chart-theme.ts`、`components/Chart.tsx` | Canvas 配色解析、业务分类颜色、图表实例更新 |
| `src/client/gantt-geometry.ts` | 工作日投影、日期索引、区间与网格计算 |
| `src/client/gantt-actual.ts` | 前端显示截止日期，不修改服务端统计规则 |
| `src/client/components/GanttDateTracks.tsx` | 计划日期与实际日期双轨绘制 |

风格只覆盖外观变量；侧栏宽度、字号、行高、面板尺寸及筛选布局由公共样式管理。普通分类图使用独立图表配色，风险、状态和优先级使用业务语义色。甘特业务色与主题强调色分开，仅针对明暗背景调整亮度。

| 甘特含义 | 六套皮肤共用表现 |
|---|---|
| 计划、未开始 | 灰色计划轮廓 |
| 执行中 | 蓝色实条 |
| 已完成、待验收 | 绿色执行条；待验收保留文字 |
| 阻塞 | 琥珀色与斜纹 |
| 已取消 | 灰色与断纹 |
| 延期 | 红色描边，保留执行条状态颜色；延期完成为绿底红边 |
| 里程碑 | 紫色标记，已达成绿色、逾期红色 |

进度显示取整不改变状态：执行中 99.6% 即使显示 100，也保持蓝色。两种视图共用上述颜色与纹理。

浮层指针移动只更新浮层。甘特日期索引按时间轴缓存；换肤更新现有 ECharts 实例，保留图例选择。

## 独立预览

实施 worktree：`D:\tools\project-manage-ui-skins`；分支：`codex/ui-skins-foundation`；基线：`dev / 9e04209`。

预览地址：`http://127.0.0.1:3220`。使用数据库快照中的原有账号登录。数据库、备份目录、Session 密钥、Cookie 名称和构建产物均独立于原服务。

在该 worktree 执行 `npm run build` 后刷新即可查看前端更新。启动服务使用 `npm start`；已有预览进程运行时无需重复启动。

需要热更新时执行 `npm run dev:web -- --host 127.0.0.1 --port 5174 --strictPort`。Vite 从独立 `.env` 读取后端端口 3220。原服务端口 3210 不参与构建、启动或测试。

- `npm run verify`：运行时、lint、单元及集成测试、构建。

- `frontend-appearance.test.ts` 检查偏好迁移、颜色解析、日期边界、取消截止。
