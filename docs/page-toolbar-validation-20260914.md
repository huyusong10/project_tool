## 复查步骤

1. 打开项目交付，检查标题栏下的层级、表格／关系图切换和操作按钮。
2. 进入特性、需求，切换视图后返回；检查原范围、选中项和筛选是否恢复。
3. 从需求管理筛选后进入需求详情，再返回；检查筛选仍在。直接打开需求链接时返回需求列表。
4. 打开流程编辑，在字段仍有焦点时保存；切回列表再进入，检查修改已生效。
5. 将窗口缩至 390px，检查保存、更多菜单和返回入口；切换到我的工作，确认不留空操作栏。
