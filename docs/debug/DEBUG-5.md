## 2026-09-10：字段与草稿对象的生命周期

工作项名称清空后删除该工作项，原来的错误字段仍留在共享草稿中。保存被拦截，但画布已经没有可以修正的对象。浏览器复现确认未发出批量提交请求。

| 场景 | 修正后的行为 |
|---|---|
| 删除对象或撤销新增 | 对象的未完成输入暂不参与保存校验；原文仍保存在本机 |
| 撤销删除、重做新增 | 恢复对象时，同步恢复原文和校验错误 |
| 撤销后编辑其他对象 | 已放弃的历史分支不再造成隐藏字段拦截 |
| 放弃草稿或保存成功 | 旧字段编辑失效，退出动画中的组件不能重新写入旧内容 |
| 修正错误后立即保存 | 使用当前字段结果，不读取修正前的错误缓存 |
| 旧草稿缺项目快照 | 用已加载的项目资料补齐对象范围，保留对象 ID、输入和撤销历史 |

项目和模板提供对象范围判断；编辑会话统一管理有效字段。判断基于完整项目及当前草稿，不依赖画布筛选、聚焦或面板是否挂载。字段集合按不可变草稿快照缓存，各卡片复用同一结果。

IndexedDB 格式仍为版本 2。删除对象的输入在保存或显式放弃前保留；本轮没有增加服务端存储、接口或业务写入。
