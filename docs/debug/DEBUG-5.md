## 2026-09-10：字段与草稿对象的生命周期

工作项名称清空后删除该工作项，原来的错误字段仍留在共享草稿中。保存被拦截，但画布已经没有可以修正的对象。浏览器复现确认未发出批量提交请求。

| 场景 | 修正后的行为 |
|---|---|
| 删除对象或撤销新增 | 对象的未完成输入暂不参与保存校验；原文仍保存在本机 |
| 撤销删除、重做新增 | 恢复对象时，同步恢复原文和校验错误 |
| 撤销后编辑其他对象 | 已放弃的历史分支不再造成隐藏字段拦截 |
| 放弃草稿或保存成功 | 旧字段编辑失效，退出动画中的组件不能重新写入旧内容 |
| 修正错误后立即保存 | 使用当前字段结果，不读取修正前的错误缓存 |
| 旧草稿缺项目快照 | 用已加载的项目资料补齐对象范围，保留对象 ID、输入和撤销历史 |

项目和模板提供对象范围判断；编辑会话统一管理有效字段。判断基于完整项目及当前草稿，不依赖画布筛选、聚焦或面板是否挂载。字段集合按不可变草稿快照缓存，各卡片复用同一结果。

IndexedDB 格式仍为版本 2。删除对象的输入在保存或显式放弃前保留；本轮没有增加服务端存储、接口或业务写入。

## 2026-09-10：跨页面错误定位与重新接管

以 `a5f8444` 为基线。浏览器复现两类问题：全局或其他需求保存时无法找到错误所属工作项；流程草稿已经接管，属性输入框仍保留本页的旧错误内容。

| 场景 | 修正后的行为 |
|---|---|
| 保存遇到其他需求的错误字段 | 打开所属需求、选中对象并聚焦原输入；保留其他有效修改 |
| 需求属性需要修正 | 返回全局中的对应需求卡片；修正后仍按整个批次保存 |
| 正常返回、页面卸载 | 保留输入，不自动跳回错误页；后续再次保存才定位错误 |
| 属性面板尚未挂载或正在关闭 | 等待可用输入框；隐藏卡片和关闭中的浮层不消耗焦点请求 |
| 重新接管草稿 | 使本页旧字段编辑失效，恢复读取到的值、错误原文和撤销历史 |
| 接管读取失败 | 展示原因，原页面保留编辑权；不丢弃输入，不自动再次提交 |
| 删除待定位对象 | 清除焦点请求；撤销可以恢复输入，但不强制抢回焦点 |

定位请求只在共享编辑会话中传递，不写入业务草稿或服务端。接管复用原有本机存储和编辑权，没有增加数据库表、接口或操作步骤。

验证结果：587 / 587 业务测试、31 / 31 Edge 浏览器场景通过；浏览器覆盖桌面、390px、全局与需求往返、项目与模板接管、错误原文、失败重试及已有编辑回归。类型检查、Lint、原生运行时和构建通过。

首次全套回归中，环境代理测试出现一次 Vite 配置加载异常；单项与整套复查均通过，保留原始报告。本轮新增浏览器用例改为等待返回地址实际变化，并按只读页面隐藏输入框的行为检查编辑权限。
