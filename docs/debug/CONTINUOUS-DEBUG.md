## 2026-09-11 跨标签待核对批次

一个标签页保存路径或流程时断线，待核对批次只写入 IndexedDB。已经打开的另一标签页不会收到变化；显式接管或原页面关闭后，它会生成新的 `batchId`，可能重复提交同一业务修改。

待核对记录继续以 IndexedDB 为准。写入或清除后通过本机存储事件通知其他标签页，通知不包含业务内容。接管过程先读取草稿和待核对批次，再解除只读状态；读取失败时保留原编辑者和输入。项目画布和流程模板自动取得编辑权后，均在保存前再次读取待核对记录；通知丢失也不会生成新批次。

新增五条浏览器回归，覆盖项目显式接管、原页面关闭后的自动交接、项目和模板通知丢失、流程模板接管。缺陷先复现为不同批次，修复后均复用原 `batchId`。项目通知丢失场景六个视口 6 / 6、完整画布回归 67 / 67、六视口流程保存旅程 48 / 48 通过。测试使用临时数据库。

## 2026-09-11 依赖排期提交锁
