## 本轮修复

| 用户操作 | 原问题 | 修复 |
|---|---|---|
| 需求开工后修改名称、协作者 | 服务端要求原因，页面没有输入入口 | 在当前编辑浮层填写原因，保存时一起提交 |
| 修改同需求尚未开始工作项的日期 | 页面按当前工作项判断，服务端按整个需求判断 | 统一按需求是否已有执行判断 |
| 中文输入法确认或取消候选 | Enter 提前保存，Esc 关闭编辑器或外层窗口 | 组合输入期间不处理这些编辑快捷键 |
| 修正必填或日期错误 | 普通校验错误显示重新读取入口，改正后旧错误仍在 | 普通错误可直接修正；版本冲突保留核对入口 |
| 保存失败后继续修改 | 名称和原因需同时保留 | 版本重读不重置输入，取消不写入业务数据 |

未开工时仍可直接编辑，不新增原因填写步骤。已有执行记录的原因要求沿用服务端规则；不修改状态、实际日期或完成度。
