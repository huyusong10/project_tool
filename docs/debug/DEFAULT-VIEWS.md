2026-09-09，基线 `1f4358d`。仅更新 `codex/continuous-debug` 的 3230／5175 前端。

| 页面 | 默认范围 | 使用目的 |
|---|---|---|
| 项目进展 | 进行中需求，按风险排序 | 首屏跟进正在推进的交付 |
| 需求管理 | 未结束需求 | 保留待规划、未开始、阻塞和待验收需求的管理入口 |

| 异常行动 | 当前可见的全部行动 | 不因需求尚未开始或正在阻塞而遗漏处理事项 |

本轮修正：

- 项目进展默认及“重置”都回到进行中、风险排序；状态选项显示项目内各状态数量。首屏无进行中需求时明确提示，可主动查看未结束需求，不自动扩大范围。
- 甘特的优先级展示、筛选和排序统一使用自动处理优先级，停止读取旧人工优先级。
- 人员筛选同时匹配需求负责人和工作项执行人，直接执行需求不再漏选。
- 行动筛选无匹配时提供清空入口，不把空结果描述为项目没有异常。

筛选只改变页面显示；首页布局、统计口径、交付预测和正式风险保持原样。用户主动选择的范围、排序和查询按账号、项目分别记忆。

旧版本会自动保存“未结束”。本次将这个旧默认改为进行中，保留原来选择的全部或具体状态；升级后再次手选“未结束”也会正常记忆。默认值不再自动写成用户偏好。
