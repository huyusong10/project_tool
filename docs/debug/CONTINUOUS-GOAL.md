- 沿用现有业务规则、接口和组件；不增加功能、跨请求业务缓存或新的架构层。当前图布局已有缓存机制，不另加一套。
- 业务计划日期0100—9999；Phase目标日期仍允许0001—0099。图视图限制不改变业务日期范围。
- 未知写入先核对原结果，不重复提交；非临时读错误清旧数据。账号身份变化清未提交草稿是既定行为。
- 性能测量单独运行，不能与构建/测试并行。浏览器模拟图只说明分析/渲染耗时，不代表真实HTTP。
- DO最初约1.1秒包含Playwright标签定位开销；CPU采样确认后改用CSS定位并重新做前后各3轮。使用校准结果，不引用原值作为应用延迟。
- CSS修改用截图确认。布局调整后的截图先等待几何稳定；长文本同时比较正文和父容器，单看页面宽度会漏掉裁切。
- 低影响样式和诊断探针不堆永久测试。已添加的恢复/权限/并发回归保留；验收后把临时探针移回证据目录。
