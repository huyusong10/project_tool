# 日常处理简化

基线 `49337d2`，开发目录 `D:\tools\project-manage-debug`，分支 `codex/continuous-debug`。本轮只更新 3230／5175，不合并、不推送。

## 操作变化

| 场景 | 当前行为 |
|---|---|
| 新建需求 | 默认无前置；选用流程时保留模板已有关系，不额外确认“没有依赖” |
| 核对预测 | 填剩余工作日或预计日期，点击保存；完成度和确认计划保持原值 |
| 影响其他需求或存在其他草稿 | 展示整个批次，点击“保存全部修改”；取消重复确认勾选 |
| 跟进阻塞 | 直接填跟进说明、下次核对日期；更换协调人和关联问题放入展开项 |
| 协调权限 | 执行负责人和经理维护协调安排；指定协调人仅维护跟进说明和日期，不能改估算、开始或解阻 |
| 异常行动 | 预测核对、阻塞跟进、验收、范围设置直接打开对应窗口；访问链接不执行命令 |
| 需求日期 | 展示预计工作完成、预计验收或实际验收，随执行阶段切换；确认计划保留在资料中，甘特不变 |
| 后台更新 | 可见页面每分钟检查版本，返回窗口时检查；只刷新数据，保留输入、焦点、草稿及个人视图 |

首页布局、默认进行中范围、风险及优先级规则保持原样。项目交付预测仍包含验收，普通执行不要求重新确认承诺。

## 历史与保存

- 承诺差异分别显示已交付、已取消、主动撤出。旧快照没有退出原因时显示“不在本次范围”，不补造原因。
- 首次承诺与最近承诺交付率都以首次真实验收作为样本；返工、再验收分别计数。后续返工或归档不抹掉已有样本。
- 旧记录只有明确验收日期、缺少验收事件时，在返工事务中保留该日期；不从说明文本推断日期。
- 没有数据库结构迁移。旧日期、布局和本机草稿不批量改写；历史未核对的依赖仍待核对。
- REST、MCP 和批量保存共用协调权限。预览不写库，失败保留输入，未知提交仍查询原批次回执。
- 表单打开后对象被他人修改时，显示最新值并保留输入；核对后再保存。不相交的后台修改自动合并，普通返回不拦截。
