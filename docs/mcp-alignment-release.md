# MCP 改版对齐记录

## 本次变化

| 位置 | 行为 |
|---|---|
| 需求查询 | 多状态、排除状态、当前阶段组合筛选；默认按名称／编号自然排序 |
| 工作项查询 | 增加特性、Phase、工作阶段筛选；默认按需求编号和流程顺序，返回归属名称 |
| 共享规则 | 网页与查询复用状态、阶段匹配和自然排序；筛选排序先于分页 |
| Phase 导出 | SVG 显示 Phase 标签、外框、交付状态和阶段百分比；内部拓扑撑开区域，保留空 Phase 与跨期依赖 |
| 布局实现 | 网页和导出共用区域布局及连线路由；不增加业务表，不改交付规则 |
| 说明 | 更新工具目录、MCP 文档和录入技能；导入只接受版本 3 |

原 `status` 参数继续可用。需要原排序时，需求传 `sort=updated`，工作项传 `sort=planned_end`。SVG 卡片实际尺寸读取 `layout.nodeSizes`，区域边界读取 `layout.regions`。参数和示例见 [MCP 文档](MCP.md)。
