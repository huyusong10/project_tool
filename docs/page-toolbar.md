# 公共页面工具栏

页面通过 `PageHeader` 发布一份声明。`App` 只挂载一个 `PageToolbar`；业务页面和编辑器不再自行绘制页面返回栏。

```text
标题栏：项目／范围 │ 模块名称                         主题 · 账号
工具栏：返回 · 层级      视图切换       状态 · 页面操作 · 更多
筛选区：搜索、阶段、负责人、日期
正文：表格、图形、详情
```

| 部件 | 职责 |
|---|---|
| `Topbar` | 项目、模块名称和个人工具，固定 52px |
| `PageToolbar` | 返回、面包屑、视图、状态、主操作和更多菜单 |
| `PageHeader` / `PageChrome` | 当前页面声明、业务回调及工作区运行环境 |
| `EditorToolbar` | 组合原有编辑命令，发布到公共工具栏 |
| `canvasNavigation` | 生成交付层级和视图声明，不绘制独立栏 |
| `page-return.ts` | 在路由条目中记录进入来源；视图和筛选变化沿用来源 |

## 使用规则

- 页面操作通过 `actions`、`secondaryActions`、`moreActions` 提供；页面视图通过 `views` 提供；层级通过 `breadcrumbs` 提供。按钮能否执行、保存和冲突处理由业务页面决定。
- 新增有操作的路由时同步更新 `toolbarForRoute`，让加载占位提前预留工具栏高度。没有页面操作或导航的页面不显示空栏。
- 独立需求详情和流程编辑的对象名称放在工具栏，标题栏保留模块名称。根页面不显示返回。
- 有层级的页面始终保留返回位，根页面留空且不可聚焦；面包屑起点固定。
- 编辑工作区固定视图、状态、撤销／重做、编辑／保存、更多操作的位置。未使用的操作位留空；状态文字超长时省略。刷新、新建特性、Phase 资料等次要操作在所有宽度下均进入更多菜单。
- 加载占位沿用同一布局。验证下钻和切换时比较按钮坐标及尺寸，不只检查是否越界。
- 返回采用当前账号仍有权访问的进入来源，跳过同一对象内的视图和筛选变更；没有有效来源时使用父级。流程编辑返回流程列表。浏览器前进、后退保持原行为。
- 返回和层级切换保留本机输入，不自动提交；保存按钮和快捷键调用原工作区的 `requestSave`，保留中文输入、无效字段及结果核对流程。
- 详情关闭、弹窗保存、表格批量操作、行内执行、图形缩放和甘特定位保留在对应区域。
- 桌面工具栏为 52px，按钮为 36px；窄屏详情和工作区预留两行 96px，次要操作进入更多菜单，保存及状态直接显示。有视图切换的窄屏编辑栏使用保存图标。触控按钮至少 44px，触屏工作区工具栏为 112px。
- 普通页面的工具栏随页面滚动吸附在标题栏下；全屏工作区由布局直接预留高度，不覆盖画布。

验证用例：`tests/responsive/page-toolbar.pw.ts`、`tests/page-return.test.ts`。业务回归继续使用交付工作区、连续画布、流程保存及 HTTP 用例。结果见[验证记录](page-toolbar-validation-20260914.md)。
